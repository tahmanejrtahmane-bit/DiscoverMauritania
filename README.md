# اكتشف موريتانيا 🇲🇷 — Android starter

نسخة Android أولية مبنية بـ Kotlin + Jetpack Compose، مستوحاة من التصميم المرفق.

- targetSdk = 36 (Android 16)
- minSdk = 26
- واجهة عربية RTL
- الرئيسية، اكتشف، الخريطة، المفضلة، حسابي
- صفحات أولية للأماكن والأرباح ونشر الفيديو

## فتح المشروع
افتح مجلد المشروع في Android Studio ثم Sync/Run.

## ما لم يُربط بعد
الدفع والسحب Bankily/Sedad/Masrivi، الحسابات وقاعدة البيانات، رفع الفيديو الحقيقي، AdMob، الإشعارات، الخرائط الحقيقية، ونظام Marketplace.
